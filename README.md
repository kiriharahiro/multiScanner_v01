# QR・NFC ハイブリッド連続スキャナー (multiScanner_v01)

スマホ・PCのブラウザで動作する、**QRコード ＆ NFCカード両対応のハイブリッド連続スキャナー**です。
画面上のタブで「📷 QRスキャナー」と「📡 NFCリーダー」をワンタップで切り替え、どちらから読み取っても**同一形式でGoogleスプレッドシート（I列〜L列）に自動記録**されます。

---

## ✨ 主な機能

- **2系統入力・ワンタップ切替**：
  - カメラによる「QRコードスキャン」（`html5-qrcode` エンジン搭載）
  - スマホ背面タッチによる「NFCカード読み取り」（Web NFC API / NTAG213, NTAG215等対応）
- **高速・連続入力**：
  - スキャン完了後も待機状態を維持し、次々の連続スキャンが可能。
- **二重読み取り防止ガード**：
  - 同一データは直近2.5秒間スキップし、誤った多重記録を防止。
- **五感フィードバック**：
  - 成功時に「ピピッ」という電子音（Web Audio API）とスマホの振動（バイブレーション）で確実にお知らせ。
- **Googleスプレッドシート自動連携**：
  - Google Apps Script (GAS) Webアプリ経由でスプレッドシートへ即座にPOST送信。
- **オフライン安心設計**：
  - 電波が途切れてもLocalStorageに一時保留され、再接続時に自動送信。

---

## 📊 スプレッドシート出力レイアウト（I列〜L列）

| 列 | 見出し | 出力内容 | NFC時 | QR時 |
| :---: | :--- | :--- | :--- | :--- |
| **I列** | `Timestamp` | 読み取り日時（JST） | `2026/09/14 10:24:15` | `2026/09/14 10:25:30` |
| **J列** | `QR/NFC Text` | 読み取ったデータ本文 | `R8_1101` | `R8_1101` |
| **K列** | `種別（QR/NFC）` | 入力モード | `NFC` | `QR` |
| **L列** | `NFC固有ID` | カードのUID | `04:A2:3B:4C:5D:6E:7F` | *(空欄)* |

## 🔒 セキュリティについて

- **認証情報の非保持**：
  本リポジトリにはGoogle Apps ScriptのURLや機密情報、APIキー、個人情報は一切ハードコードされていません。
- **ローカル設定方式**：
  送信先GASのURLは、各ユーザーがアプリ画面の設定（⚙️）からブラウザ内（LocalStorage）にのみ保存する安全な構成になっています。

---

## 🚀 使い方

1. **Googleスプレッドシート側の準備**：
   - スプレッドシートの「拡張機能」>「Apps Script」に `gas-script.js` の内容を貼り付け、「ウェブアプリ」としてデプロイします。
   - 詳細は [`操作手順書.md`](./操作手順書.md) をご覧ください。
2. **アプリの起動**：
   - 静的Webホスティング（Vercel, GitHub Pages等）またはローカルサーバー（`start-server.ps1`）で `index.html` を開きます。
3. **設定の登録**：
   - 画面右上の ⚙️ アイコンから、発行されたGASウェブアプリURLを登録します。
